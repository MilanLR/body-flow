# Design: Missing Images Local Replacement & WebP Optimization

## Problem Statement
The BodyFlow Amsterdam website previously referenced four external images hosted on an Amazon CloudFront CDN (`d2xsxph8kpxj0f.cloudfront.net`) generated by an early Manus scaffolding run. All four URLs currently return `HTTP 403 Forbidden` (Access Denied / bucket decommissioned), causing missing visuals on key sections:
1. **Hero section background** (`HERO_BG` in `Hero.tsx`)
2. **EECP therapy session showcase** (`EECP_THERAPY` in `EECP.tsx`)
3. **Vitality banner background** (`VITALITY` in `VitalityBanner.tsx`)
4. *(Unused)* `HEART_HEALTH` in `constants.ts`

## Goals
- Replace all missing remote image dependencies with self-hosted local static assets under `client/public/images/`.
- Optimize source images to modern WebP format (~85–88% quality) to reduce file transfer size by ~90–95% while maintaining crisp visual quality.
- Update `constants.ts` to reference the local assets.
- Eliminate third-party CDN dependency risks so the site remains permanently self-contained.
- Commit all changes and push to `origin/main`.

## Non-Goals
- Modifying UI layouts or component structure (the existing aspect ratios and CSS classes are preserved).
- Removing or altering existing functional icons or partner logos in `client/public/`.

## Asset Mapping & Specification

| Source File | Destination | Dimensions | Target Format | Web Role |
|---|---|---|---|---|
| `~/Downloads/hero.jpg` (~1.7 MB) | `client/public/images/hero-bg.webp` | 2608×1600 | WebP (~150–250 KB) | Background for Hero section (`HERO_BG`) |
| `~/Downloads/EECP_foto.png` (~4.6 MB) | `client/public/images/eecp-therapy.webp` | 1776×2235 (3:4 ratio) | WebP (~180–300 KB) | Portrait card in EECP section (`EECP_THERAPY`) |
| `~/Downloads/other.jpg` (~3.2 MB) | `client/public/images/vitality.webp` | 3168×1344 (panoramic) | WebP (~150–250 KB) | Wide banner in Vitality section (`VITALITY`) |

## Technical Implementation

### 1. Asset Conversion Pipeline
Using Python (`Pillow`) to read each source file from `~/Downloads`, convert RGB color space, and save to `client/public/images/` as WebP with `quality=88` and `method=6` (optimal compression effort).

### 2. Code Updates
Update `client/src/sections/constants.ts`:
```ts
export const HERO_BG = "/images/hero-bg.webp";
export const EECP_THERAPY = "/images/eecp-therapy.webp";
export const VITALITY = "/images/vitality.webp";
```
Remove the obsolete unused `HEART_HEALTH` constant.

### 3. Verification
- Verify generated image files exist in `client/public/images/` and have expected dimensions and valid WebP headers.
- Execute unit and lint tests: `pnpm test`.
- Execute production build: `pnpm build` to confirm Vite correctly bundles and copies the public assets into `dist/public`.

### 4. Git & Deployment
- Stage new WebP images in `client/public/images/`, `constants.ts`, and spec documentation.
- Create a clean git commit.
- Push commit to remote `origin/main`.
